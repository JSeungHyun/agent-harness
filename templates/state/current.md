# 진행 상태 대장

> 상태: **설계안**

어디까지 갔는지가 **대화가 아니라 이 파일에 있다.** 세션이 끊겨도 `node .harness/tools/state-check.mjs` 한 번이면 이어받는다.

| 값 | 뜻 |
|---|---|
| `분석완료` | 끝까지 읽고 대조했다 |
| `부분분석` | 일부만 봤다 — 다시 봐야 한다 |
| `미분석` | 아직 열어보지 않았다 |
| `해당없음` | 대상 밖 |

**해시가 바뀌면 상태가 무효가 된다.** `state-check` 가 그 행을 재작업 대상으로 돌려보내며 현재 해시를 알려준다.

⛔ **읽은 척하지 않는다.** 일부만 본 것은 `부분분석` 이다.
